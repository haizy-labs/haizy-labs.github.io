Mermaid Editor Pro for Confluence Cloud

Version 2.1.0

Getting Started

Mermaid Editor Pro adds a powerful visual Mermaid diagram editor directly into your Confluence pages. Create flowcharts, sequence diagrams, Gantt charts, and more using Mermaid syntax with a live preview.

Installation

  1. Install Mermaid Editor Pro from the Atlassian Marketplace.
  2. Once installed, the app is available in your Confluence instance.
  3. No additional configuration is required.

Using the Editor

Adding a Diagram

  1. Edit any Confluence page.
  2. Type /Mermaid Editor Pro in the page editor and select the macro from the dropdown.
  3. Enter your Mermaid diagram syntax in the editor panel.
  4. See a live preview update as you type on the right side.
  5. Save the page to embed the diagram.

Supported Diagram Types

  • Flowcharts
  • Sequence Diagrams
  • Class Diagrams
  • State Diagrams
  • Entity Relationship Diagrams
  • Gantt Charts
  • Pie Charts
  • Git Graphs
  • Mind Maps
  • Timeline Diagrams
  • And more
